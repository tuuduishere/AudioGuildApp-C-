Tóm tắt dự án

Tên: AudioGuideApp

Mục tiêu: Ứng dụng hướng dẫn du lịch bằng audio tự động theo vị trí. Cung cấp POI (points of interest) với popup chi tiết, chức năng chỉ đường cơ bản, chế độ offline cho audio/data, và trang quản trị để quản lý nội dung.

Stack hiện tại: Mobile app: .NET MAUI (net10); Bản đồ: WebView + Leaflet; Backend: .NET Web API; Admin: Razor Pages; Dữ liệu mẫu: MockData.Destinations.

Mục tiêu sản phẩm

  • Cho phép người dùng xem POI trên bản đồ, mở popup và xem chi tiết.
  • Hỗ trợ nghe audio mô tả tự động khi tới gần POI, và lưu audio offline.
  • Cung cấp trang quản trị để upload ảnh, audio và quản lý POI.

Timeline kỹ thuật (Startup & Data Flow)

1

Tầng 1 — Kiểm tra cấu hình bảo mật

Kiểm tra biến môi trường quan trọng: JWT_SECRET, REFRESH_TOKEN_SECRET, PII_ENCRYPTION_KEY. Từ chối khởi động nếu thiếu.

2

Tầng 2 — Kết nối Database

Kết nối MongoDB (uri cấu hình). Kiểm tra connectivity, retry policy.

3

Tầng 3 — Data Seeding

Tạo default roles và super-admin khi lần đầu khởi động nếu chưa có.

4

Tầng 4 — Indexing

Tạo index 2dsphere trên pois.location và compound index trên poi_localizations(poi_id, lang).

5

Gắn Routers — Server Ready

Mount các router: content, audio, admin, auth, maps — prefix /api/v1.

Phạm vi

Giai đoạn 1 bao gồm MAUI client (Map, Explore, Detail, Favorites), Admin Razor Pages cơ bản, và Backend API CRUD POI. Không bao gồm thanh toán, booking hay routing nâng cao (có thể tích hợp sau).

Người dùng (Personas)

  • Visitor: Khách du lịch muốn khám phá — cần UI trực quan, offline audio, chỉ đường cơ bản.
  • Admin / Content Editor: Upload POI, audio, ảnh, quản lý nội dung.

Yêu cầu chức năng (Functional Requirements)

Map & POI (Ưu tiên cao)

  • Hiển thị POI từ backend hoặc MockData khi offline.
  • Popup marker có tên, rating, giá, thumbnail, nút "Xem chi tiết" và "Chỉ đường".
  • Click "Xem chi tiết" mở DetailPage (Shell route "detail" nhận query param id hoặc name).
  • Click "Chỉ đường" bật RouteMode, lấy vị trí thiết bị (nếu có), vẽ polyline giữa origin và destination.
  • Hỗ trợ pan/zoom mượt, clustering khi có nhiều POI (nâng cấp).

Detail Page (Ưu tiên cao)

  • Hiển thị carousel ảnh, tên, rating, giá, mô tả, các hành động: Fav, Share, Directions.
  • Share tích hợp Share.Default (MAUI).
  • Hỗ trợ mở từ app:// link trong WebView.

Audio (Ưu tiên cao)

  • Mỗi POI có audio theo ngôn ngữ; hỗ trợ tải offline.
  • Tự động phát khi user trong bán kính cấu hình (ví dụ 50m).

Admin (Ưu tiên cao)

  • Authentication (JWT), CRUD POI, upload audio/ảnh, list/search.

Dữ liệu & Mô hình

Mô hình POI (POI / Destination):

  • id (GUID) — khoá chính
  • name — tên POI
  • lat, lng — tọa độ (double)
  • description — mô tả dài (markdown hoặc plain)
  • images[] — danh sách URL ảnh
  • audios[] — danh sách audio { lang, url, duration }
  • rating, price, category, tags
  • isFeatured, createdAt, updatedAt

Bảng cấu trúc MongoDB (ví dụ các collection)

CollectionVí dụ trườngMục đích
pois_id, name, location:{type:'Point', coordinates:[lng,lat]}, images, price, rating, tagsDữ liệu POI gốc, geojson location cho 2dsphere index
poi_localizationspoi_id, lang, title, description, audio_urlBản dịch & audio per language
admin_users_id, email, passwordHash, roleIds, createdAtTài khoản admin

Ghi chú indexing: tạo index 2dsphere trên pois.location để hỗ trợ truy vấn gần (nearSphere). Tạo compound index trên poi_localizations(poi_id, lang) để lookup nhanh.

API Contract (ví dụ)

Dưới đây là một số endpoint chính (REST) và ví dụ request/response:

1) Lấy POI theo vùng / gần

GET /api/pois?lat=10.77&lng=106.70&radius=1000&page=1&pageSize=50
Response 200
{
  "items": [ { "id":"...","name":"Chợ Bến Thành","lat":10.772,"lng":106.698,"thumbnail":"/img/.." } ],
  "total": 4
}

2) Lấy POI chi tiết

GET /api/pois/{id}
Response 200
{
  "id":"...",
  "name":"Chợ Bến Thành",
  "description":"...",
  "images": ["/img/1.jpg"],
  "audios": [{"lang":"vi","url":"/audio/vi/..mp3","duration":42}]
}

3) Tạo / cập nhật POI (admin)

POST /api/pois  (body: JSON)
{
  "name":"...", "lat":10.77, "lng":106.7, "category":"food"
}
Response 201 { "id":"..." }

4) Upload audio

POST /api/pois/{id}/upload-audio  (multipart/form-data)
Form fields: file (mp3), lang (vi/en)
Response 200 { "audioUrl":"/audio/vi/..mp3" }

Authentication: Bearer token (JWT) cho các endpoint admin. Các endpoint public (GET pois) không yêu cầu auth.

UX / UI Spec

Navigation chính: Shell TabBar (Explore, Map, Food, Favorites). MapPage chứa WebView full-screen + FAB locate + Cancel Route. Popup marker có thumbnail, tên, rating, price, nút Xem chi tiết & Chỉ đường. DetailPage: carousel ảnh, title, subtitle (rating • price), mô tả, nút hành động.

Non-functional Requirements

  • Performance: Map load nhanh, audio start nhanh cho local files.
  • Reliability: Offline-first cho audio đã tải.
  • Security: Admin endpoints bảo vệ bằng JWT, HTTPS, validate uploads.
  • Compatibility: Windows, Android, iOS via MAUI.

Offline & Sync Strategy

Cache POI list (SQLite) và audio files cho chế độ offline. Sync khi có mạng, versioning dựa trên timestamp.

Tests & Acceptance Criteria

  • AC1: Map hiển thị markers cho POI mock.
  • AC2: Marker popup & Xem chi tiết mở đúng POI.
  • AC3: Directions hiển thị polyline khi bật RouteMode.
  • AC4: Audio offline playback hoạt động.

Deployment & Operations

MAUI builds: Android APK, Windows appx, iOS. Backend deploy: Azure App Service. CI/CD: GitHub Actions build & publish.

Security & Privacy

Không thu PII ngoài cần thiết; location lưu local; admin auth + TLS; validate uploads & file size limit.
