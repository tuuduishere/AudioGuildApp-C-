Tổng Quan Sản Phẩm

TravelSmart Vĩnh Khánh là ứng dụng di động (.NET MAUI) giúp du khách khám phá phố ẩm thực Vĩnh Khánh — Quận 4, TP.HCM — thông qua bản đồ tương tác, hệ thống thuyết minh tự động bằng giọng nói kích hoạt theo vị trí GPS, và hỗ trợ hoàn toàn offline.

🎯 Mục tiêu cốt lõi:

Du khách chỉ cần mở app và đi dạo — hệ thống tự động nhận biết khi họ đến gần một điểm ẩm thực (POI) và phát thuyết minh giọng nói, không cần thao tác thêm. Hỗ trợ cả chế độ QR tại các điểm dừng xe buýt để dùng không cần GPS.

🧑‍🦱 Người dùng mục tiêu

  • Du khách trong nước lần đầu ghé Vĩnh Khánh
  • Người nước ngoài muốn khám phá ẩm thực địa phương
  • Học sinh, sinh viên tham quan thực tế
  • Người dùng tại điểm dừng xe buýt (Khánh Hội, Vĩnh Tạ, Xóm Chiếu)

💡 Vấn đề giải quyết

  • Thiếu hướng dẫn tại chỗ cho phố ẩm thực nhỏ
  • Du khách không biết điểm nào đặc biệt, có lịch sử gì
  • Rào cản ngôn ngữ với khách nước ngoài
  • Không có internet ổn định trong khu vực hẻm nhỏ

🏆 Điểm khác biệt

  • Geofence tự động — không cần bấm nút
  • Offline-first với SQLite, sync khi có mạng
  • QR Code tại trạm xe buýt — zero GPS
  • TTS linh hoạt: file audio sẵn + fallback TTS live

Chương 02

GPS Tracking & Geofence Engine

📡 GPS Tracking thời gian thực

  • Lấy vị trí người dùng liên tục (foreground + background)
  • Tối ưu pin: giảm tần suất khi người dùng đứng yên
  • Độ chính xác cao (fine location), fallback coarse khi cần
  • Hiển thị trên bản đồ với marker thời gian thực

🔔 Geofence — Kích Hoạt Điểm POI

  • Thiết lập vùng POI với: tọa độ, bán kính, mức ưu tiên
  • Tự động phát thuyết minh khi người dùng vào vùng hoặc đến gần điểm
  • Chống spam: Debounce + Cooldown giữa các lần kích hoạt
  • Hỗ trợ cả chế độ "đi vào vùng" và "gần điểm nhất"

⚙️ Cấu hình Geofence

  • radius: bán kính kích hoạt (mét)
  • priority: mức ưu tiên khi nhiều POI chồng nhau
  • cooldown_sec: thời gian chờ giữa 2 lần kích hoạt cùng POI
  • trigger_on: enter / dwell / nearest

🔋 Tối Ưu Pin

  • Background location với WorkManager / BackgroundService
  • Giảm tần suất GPS khi tốc độ di chuyển thấp
  • Dùng Geofence API của OS thay vì polling thủ công
  • Thông báo foreground service để duy trì độ chính xác

Luồng kích hoạt Geofence

GPS cập nhật vị trí → Tính khoảng cách đến POI → Vào vùng / Gần nhất? → Cooldown check → Đẩy vào hàng chờ TTS → 🔊 Phát audio

Chương 03

Thuyết Minh Tự Động — TTS Engine

Chiến lược 2 tầng:

Ưu tiên dùng file audio thu sẵn (giọng tự nhiên, chuyên nghiệp). Nếu không có, fallback sang Text-to-Speech (TTS) linh hoạt, đa ngôn ngữ, dùng dữ liệu nội dung từ API.

🎙️ File Audio Thu Sẵn

  • Giọng tự nhiên, chuyên nghiệp — chất lượng cao nhất
  • Lưu trữ theo POI: /audio/{poi_id}/{lang}.mp3
  • Cache local SQLite + file system
  • Ưu tiên phát trước khi dùng TTS

🤖 Text-to-Speech (TTS)

  • Linh hoạt, đa ngôn ngữ — fallback khi thiếu audio sẵn
  • Dùng dữ liệu script/nội dung từ POI record
  • Nhẹ nhàng — không quá dramatic
  • Hỗ trợ tối thiểu: Tiếng Việt + Tiếng Anh

📋 Hàng Chờ Audio

  • Queue FIFO — phát tuần tự, không chồng chéo
  • Tự dừng khi có thông báo hệ thống khác
  • Resume sau khi thông báo kết thúc
  • Skip nếu người dùng rời khỏi vùng POI

🌐 Đa Ngôn Ngữ

  • Phát theo ngôn ngữ cài đặt của app
  • Script TTS lưu trong POI record theo từng ngôn ngữ
  • Admin có thể thêm/sửa script từng ngôn ngữ trên CMS
  • Fallback: Tiếng Việt nếu không có ngôn ngữ yêu cầu

Pipeline xử lý Audio — 4 Tầng Fallback

Tier 1
File Audio Thu Sẵn (0ms, chất lượng cao nhất) Kiểm tra local cache → nếu có, phát ngay. Không cần mạng, không cần xử lý.
Tier 2
File Audio từ Server (yêu cầu mạng, 1-3s) Download MP3 từ API → cache local → phát. Lần sau dùng Tier 1.
Tier 3
TTS Live (yêu cầu mạng, 2-5s) Gọi TTS API với script text → nhận audio stream → phát. Cache kết quả.
Tier 4
Device TTS Offline (0ms, chất lượng thấp nhất) Dùng SpeechSynthesis của hệ điều hành. Luôn khả dụng kể cả offline.

Chương 04

Quản Lý Dữ Liệu POI

POI (Point of Interest) là đơn vị dữ liệu trung tâm của hệ thống — mỗi quán ăn, điểm đặc sản trên phố Vĩnh Khánh là một POI.

📄 Cấu trúc dữ liệu POI

  • id: định danh duy nhất
  • name: tên điểm ẩm thực
  • description: mô tả văn bản
  • coordinates: tọa độ GPS (lat, lng)
  • radius_m: bán kính geofence (mét)
  • images[]: ảnh minh hoạ
  • map_link: link Google Maps
  • audio_files{}: dict ngôn ngữ → file audio
  • tts_scripts{}: dict ngôn ngữ → script TTS

💾 Offline Storage (SQLite)

  • Toàn bộ POI lưu local SQLite khi có mạng
  • Sync tự động khi kết nối lại (background)
  • So sánh updated_at để chỉ sync phần thay đổi
  • App hoạt động đầy đủ kể cả khi mất mạng hoàn toàn

🔄 Vòng đời dữ liệu POI

  • Admin tạo/sửa POI trên CMS (web)
  • Server lưu + xử lý audio background
  • App sync khi mở / có mạng
  • App dùng SQLite local cho mọi truy vấn
Thiết kế Offline-First:

Mọi truy vấn POI đều đọc từ SQLite local trước. Kết nối mạng chỉ dùng để sync — không bao giờ block trải nghiệm người dùng.

Analytics — Phân Tích Dữ Liệu

🗺️ Lưu tuyến di chuyển

  • Ghi lại hành trình người dùng (ẩn danh)
  • Không lưu thông tin định danh cá nhân

QR Code — Kích Hoạt Nội Dung Tại Trạm Xe Buýt

Ý tưởng độc đáo:

Đặt QR code tại điểm dừng xe buýt (Khánh Hội, Vĩnh Tạ, Xóm Chiếu) — hành khách ngồi chờ xe, quét QR là nghe thuyết minh ngay. Không cần GPS, không cần di chuyển.

📍 3 Điểm dừng xe buýt

  • 🚌 Khánh Hội
  • 🚌 Vĩnh Tạ
  • 🚌 Xóm Chiếu
  • Mỗi điểm có QR riêng → POI riêng

⚡ Trải nghiệm quét QR

  • Quét bằng camera → mở app / deeplink
  • App đọc POI ID từ QR → load nội dung local
  • Phát thuyết minh ngay lập tức
  • Không cần GPS, không cần internet (nếu đã sync)

🔒 Hoạt động offline

  • Nội dung POI đã có sẵn trong SQLite local
  • QR chỉ chứa POI ID — không cần fetch thêm
  • File audio thu sẵn cache local → phát ngay
  • Lý tưởng cho vùng tín hiệu yếu

Luồng QR Code

Hành khách chờ xe buýt → Quét QR trên biển → App mở (deeplink) → Đọc POI ID từ QR → Load từ SQLite local → 🔊 Phát thuyết minh

Roadmap Phát Triển

PoC

Sprint 1–2 — Hạ tầng & GPS Core

Cài đặt solution, setup MAUI + API + Admin. Implement GPS Tracking foreground/background. Màn hình bản đồ cơ bản hiển thị vị trí người dùng.

PoC

Implement Geofence Engine với debounce/cooldown. Xây dựng TTS hàng chờ audio. Thêm POI mẫu Vĩnh Khánh. Test kích hoạt thuyết minh trên thiết bị thật.

PoC

MVP

MVP

Blazor Admin: CRUD POI, upload audio, quản lý bản dịch. Analytics dashboard: top POI, tuyến di chuyển, heatmap.

MVP

Sprint 10 — Polish & Deploy

UI/UX hoàn thiện, test hiệu năng pin, test offline edge cases. Deploy API lên server. Chuẩn bị demo thực tế.
