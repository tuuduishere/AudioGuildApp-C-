Tổng Quan Sản Phẩm

TravelSmart Vĩnh Khánh là ứng dụng di động (.NET MAUI) giúp du khách khám phá phố ẩm thực Vĩnh Khánh — Quận 4, TP.HCM — thông qua bản đồ tương tác, hệ thống thuyết minh tự động bằng giọng nói kích hoạt theo vị trí GPS, và hỗ trợ hoàn toàn offline.

🎯 Mục tiêu cốt lõi:

Du khách chỉ cần mở app và đi dạo — hệ thống tự động nhận biết khi họ đến gần một điểm ẩm thực (POI) và phát thuyết minh giọng nói, không cần thao tác thêm. Hỗ trợ cả chế độ QR tại các điểm dừng xe buýt để dùng không cần GPS.

🧑‍🦱 Người dùng mục tiêu

  • Du khách trong nước lần đầu ghé Vĩnh Khánh
  • Người nước ngoài muốn khám phá ẩm thực địa phương
  • Học sinh, sinh viên tham quan thực tế
  • Người dùng tại điểm dừng xe buýt (Khánh Hội, Vĩnh Tạ, Xóm Chiếu)

💡 Vấn đề giải quyết

  • Thiếu hướng dẫn tại chỗ cho phố ẩm thực nhỏ
  • Du khách không biết điểm nào đặc biệt, có lịch sử gì
  • Rào cản ngôn ngữ với khách nước ngoài
  • Không có internet ổn định trong khu vực hẻm nhỏ

🏆 Điểm khác biệt

  • Geofence tự động — không cần bấm nút
  • Offline-first với SQLite, sync khi có mạng
  • QR Code tại trạm xe buýt — zero GPS
  • TTS linh hoạt: file audio sẵn + fallback TTS live

Chương 02

GPS Tracking & Geofence Engine

📡 GPS Tracking — IDispatcherTimer

  • Timer 5 giây: Application.Current.Dispatcher.CreateTimer()
  • Mỗi tick: Geolocation.GetLocationAsync(GeolocationAccuracy.Medium, timeout:2s)
  • Yêu cầu quyền Permissions.LocationWhenInUse khi khởi động
  • MyMap.IsShowingUser = true — hiển thị vị trí user trên bản đồ MAUI Maps

🔔 Geofence — Tính Thủ Công

  • Không dùng OS Geofence API — tự tính bằng Location.CalculateDistance(DistanceUnits.Kilometers)
  • Bán kính cấu hình: Preferences.Default.Get("GeofenceRadius", 50) (mặc định 50m)
  • Sắp xếp: OrderBy(Item2=khoảng cách).ThenByDescending(Item1.Priority).ThenBy(Name)
  • Exit detection: distance > radius + 50m buffer → ghi nhận thời gian ở lại

⚙️ Cooldown & Stop Logic

  • Cooldown: _poiCooldowns[poi.Id] — nếu chưa đủ 3 phút thì skip
  • Vào POI mới: StopSpeech() → hủy CancellationToken + dispose _audioPlayer
  • Highlight active POI: vẽ Circle đỏ bán kính currentRadiusKm trên bản đồ
  • Tắt khi rời POI: ClearHighlight() xóa circle khỏi MapElements

🔴 SignalR Real-time

  • Kết nối: /travelhub?clientType=app với WithAutomaticReconnect()
  • Vào quán: SendAsync("JoinPoi", poi.Id.ToLower())
  • Rời quán: SendAsync("LeavePoi", poi.Id.ToLower())
  • Admin web nhận realtime: biết số người đang ở từng POI tại thời điểm đó

Luồng kích hoạt Geofence

IDispatcherTimer tick 5s → Geolocation.GetLocationAsync(Medium) → Location.CalculateDistance() mỗi POI → Gom POI trong bán kính → sort Priority → Cooldown check 3 phút → StopSpeech() → PlayPoiAudio(poi) → 🔊 Phát audio + OpenBottomSheet

Thuyết Minh Tự Động — TTS Engine

Chiến lược 4 bước — hàm PlayPoiAudio(PoiModel poi, string tempLangOverride = null):

Mỗi lần vào vùng POI, app gọi StopSpeech() trước (dừng audio cũ), sau đó thử từng bước theo thứ tự ưu tiên. Không có Queue FIFO — audio mới thay thế ngay audio cũ.

Pipeline PlayPoiAudio() — 4 Bước Fallback Thực Tế

Bước 0
Audio Gốc do Admin Upload (poi.AudioUrl) — chất lượng cao nhất Nếu Admin đã upload file riêng qua CMS: download về cache manual_{poi.Id}.mp3 → AudioManager.Current.CreatePlayer(stream).Play() → return. Giọng thu âm chuyên nghiệp, đúng ngữ điệu địa phương.
Bước 1
Cache Local đã có sẵn — File.Exists("{poi.Id}_vi.mp3") Kiểm tra FileSystem.CacheDirectory/{poi.Id}_vi.mp3. Nếu có → File.OpenRead() → AudioManager.Current.CreatePlayer(stream).Play() → return. Không cần mạng, 0ms.
Bước 2
Download EdgeTTS từ Server — GET /audio/{poi.Id}_vi.mp3 Nếu có mạng (Connectivity.Current.NetworkAccess == NetworkAccess.Internet): httpClient.GetByteArrayAsync(url) → File.WriteAllBytesAsync(localPath) → play. Lần sau dùng Bước 1. Server không có → catch → xuống Bước 3.
Bước 3
SmartSpeak — Google Translate + TextToSpeech.Default.SpeakAsync() Dịch poi.TtsContent sang ngôn ngữ đích qua translate.googleapis.com (vi/en/ja). Sau đó dùng TextToSpeech.Default.SpeakAsync(text, SpeechOptions{Locale, Pitch, Volume}, cancelToken). Offline thì fallback text cứng.

🌐 Đa Ngôn Ngữ — vi / en / ja

  • Lần đầu mở app: DisplayActionSheet chọn 🇻🇳 Tiếng Việt / 🇬🇧 English / 🇯🇵 日本語 → lưu Preferences["DefaultLang"]
  • Nút chuyển ngôn ngữ tức thì: OnLangClicked → PlayPoiAudio(poi, "en"/"ja")
  • SmartSpeak translate URL: translate.googleapis.com/translate_a/single?client=gtx&sl=vi&tl={lang}&dt=t&q={text}
  • Header giả Chrome: User-Agent: Mozilla/5.0 ... Chrome/91 để bypass Google Translate bot protection
  • Giới hạn: truncate 1000 ký tự, sanitize \r\n → space, escape " → '
  • Offline + lang != vi → fallback: "App is offline." / "オフラインです"

⏱️ Cooldown & Stop Logic

  • Cooldown 3 phút/POI — _poiCooldowns[poi.Id] dictionary
  • Vào POI mới → StopSpeech(): cancel CancellationTokenSource + _audioPlayer.Stop().Dispose()
  • TtsSpeed: Preferences.Default.Get("TtsSpeed", 1.0f) — đọc nhưng chưa pass vào SpeechOptions
  • Thoát vùng geofence (+50m buffer) → _entryTimes.Remove(poiId)

📡 SignalR — Real-time Tracking

  • Hub URL: ApiBaseUrl.Replace("/api", "/travelhub?clientType=app")
  • Header bắt buộc: ngrok-skip-browser-warning: true cho tất cả API call qua Cloudflare
  • Vào quán: SendAsync("JoinPoi", poi.Id.ToLower()) — bắt buộc lowercase để khớp server
  • Đóng sheet / rời quán: SendAsync("LeavePoi", poi.Id.ToLower())
  • Web Admin kết nối: clientType=admin (không phải "web") → nhận UpdateOnlineCount + UpdateViewerCount(poiId, count)

💾 SQLite Offline-First

  • DB: TravelSmartLocal.db3 — bảng PoiModel + VisitLogModel
  • Delta sync: GET /api/Pois?_t={ticks} → insert/update/delete so sánh Id
  • Android emulator: URL replace localhost → 10.0.2.2, https:7008 → http:5088; SSL bypass ServerCertificateCustomValidationCallback = true
  • History log: ghi SQLite local trước → POST /api/Pois/history nếu có mạng

Quản Lý Dữ Liệu POI

POI (Point of Interest) là đơn vị dữ liệu trung tâm — mỗi quán ăn, điểm đặc sản trên phố Vĩnh Khánh là một POI. Toàn bộ tính năng Geofence, TTS, QR, Analytics đều xoay quanh model này.

🗃️ PoiModel — Cấu Trúc Dữ Liệu Thực Tế

Id
string (Guid)
PrimaryKey SQLite. App dùng string Guid, PoC API dùng int — cần đồng nhất khi production
✅ PoC API
Name
string
Tên quán ăn — hiển thị trên Pin bản đồ, bottom sheet, sort geofence
✅ PoC API
Latitude / Longitude
double
Tọa độ GPS. Dùng để tính khoảng cách geofence và vẽ Pin, Circle, Polyline trên bản đồ
✅ PoC API
Radius
double (mét)
Bán kính geofence của từng POI. App override bởi Preferences["GeofenceRadius"] (mặc định 50m)
✅ PoC API
TtsContent
string
Script thuyết minh tiếng Việt — input cho SmartSpeak(), truncate 1000 ký tự khi dịch
✅ PoC API
QrCodeKey
string
Khớp với chuỗi QR tại trạm xe buýt. VD: "VK_OC_OANH" → parse từ poi=VK_OC_OANH
✅ PoC API
Description
string
Mô tả ngắn hiển thị trong bottom sheet trước khi fetch detail từ API
✅ PoC API

❌ Thiếu PoC

❌ Thiếu PoC

❌ Thiếu PoC
⚠️ Bug cần fix trước production — AnalyticsLog không khớp

PoC API lưu AnalyticsLog{PoiId, ActionType, Timestamp} nhưng App thực tế gửi {PoiId, DeviceName, LanguageCode, DurationMinutes}. Production API cần thêm 3 field này và bỏ ActionType.

  • Name — tên POI trong tour

  • API: GET /api/Tours/{id}/details → vẽ Polyline theo Order

QR Code — Kích Hoạt Nội Dung Tại Trạm Xe Buýt

Ý tưởng độc đáo:

Đặt QR code tại điểm dừng xe buýt (Khánh Hội, Vĩnh Tạ, Xóm Chiếu) — hành khách ngồi chờ xe, quét QR là nghe thuyết minh ngay. Không cần tài khoản, không cần GPS, không cần đăng nhập.

📷 ScannerPage — Camera QR

  • Nút camera ở MainPage → mở ScannerPage dưới dạng modal
  • Dùng thư viện camera MAUI để decode QR realtime
  • QR chứa chuỗi dạng: poi=VK_OC_OANH (QrCodeKey prefix)
  • Decode xong → đóng modal → trả kết quả về MainPage

🔑 QrCodeKey Matching

  • Parse chuỗi: key.Contains("poi=") → Split("poi=")[1].Split("&")[0]
  • Tra SQLite local: _pois.FirstOrDefault(p => p.QrCodeKey == key)
  • Nếu có → delay 500ms → PlayPoiAudio(poi) + OpenBottomSheetForPoi(pin, poi)
  • Nếu không có → DisplayAlert("Rất tiếc", "Mã QR này không thuộc hệ thống!", "OK")

🔒 Hoạt động Offline — Guest Mode

  • Không yêu cầu đăng nhập — SecureStorage["role"] == "Guest" vẫn dùng được
  • POI đã có sẵn trong SQLite → 0ms, không cần mạng
  • Audio cache local → phát ngay qua AudioManager.Current.CreatePlayer()
  • Log lịch sử: AddHistoryAsync(poi) → ghi local → sync lên server khi có mạng

⚙️ Quản lý QR — Admin

  • Admin set poi.QrCodeKey khi tạo POI trên Pois.razor
  • Mỗi điểm dừng xe buýt có key riêng: VK_OC_OANH, VK_VINH_TA...
  • Cập nhật Cloudflare URL trên Home.razor → sinh QR mới → in dán lại biển
  • QR encode URL: {cloudflareUrl}?poi={QrCodeKey}

Luồng QR Code — Thực Tế

Hành khách quét QR tại trạm → ScannerPage decode → chuỗi "poi=VK_OC_OANH" → Tách key → tra SQLite _pois → Tìm thấy PoiModel khớp QrCodeKey → OpenBottomSheet + PlayPoiAudio(poi) → 🔊 Phát thuyết minh ngay
